## 🏛 THE WORKS

### `llvm-project`
Contributing to compiler infrastructure across areas including LLVM optimization, libc++ and Flang/OpenMP.  
**Focus:** compiler infrastructure · optimization · C++ · LLVM

---

### `wild`
A high-performance Linux linker written in Rust. Contributions include linker-script support, symbol handling, debugging infrastructure and related linker behavior.  
**Focus:** Rust · ELF · linkers · Linux · toolchains

---

### `paradedb`
Search and database infrastructure built around PostgreSQL and Rust.  
**Focus:** Rust · databases · search · PostgreSQL · infrastructure

---

### `rivet`
Distributed infrastructure for durable actors and agentic workloads. Currently exploring client reliability, connection behavior and systems-level infrastructure.  
**Focus:** Rust · distributed systems · networking · infrastructure

---

### `Sangrah`
Governance-first federated AI infrastructure. The broader system explores local model training, privacy-preserving updates and robust aggregation for organizations.  
**Focus:** federated learning · Rust · AI infrastructure · privacy

---

### `Weavr`
A product for turning saved content into structured, searchable and actionable knowledge. The system combines mobile development, local-first architecture, backend infrastructure, AI processing and subscription infrastructure.  
**Focus:** product engineering · mobile · backend systems · AI

---

### `DeFi Insta`
A decentralized social application built on Solana using Anchor. Features include blockchain-based profiles, posts, likes, comments, wallet integration and IPFS-backed content.  
**Focus:** Solana · Rust · Anchor · Web3 · smart contracts
